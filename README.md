# ศึกเทพหิมพานต์ · เว็บเกม

บอร์ดเกมเทพไทยแบบผลัดตา 2–7 คน เล่นผ่านเว็บ เพื่อนกดลิงก์แล้วเล่นได้ทันที ไม่ต้องสมัครอะไร

ขึ้นเว็บใช้ 2 บริการฟรี:
- **GitHub Pages** เป็นที่ฝากหน้าเว็บ
- **Firebase** เป็นฐานข้อมูลเก็บห้องเล่น และระบุตัวผู้เล่นแบบไม่ต้องล็อกอิน

ใช้เวลาตั้งค่าครั้งแรกประมาณ 20–30 นาที ทำครั้งเดียวจบ

---

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
| --- | --- |
| `index.html` | หน้าเว็บหลัก |
| `css/style.css` | หน้าตา สี ตัวอักษร (มีโหมดมืดในตัว) |
| `js/rules.js` | **กติกาเกมทั้งหมด** แยกจากหน้าจอ ถ้าวันหนึ่งย้ายไป Godot หรือ Unity ใช้ไฟล์นี้เป็นแบบได้ |
| `js/app.js` | หน้าจอ ปุ่ม แผนที่ บทเรียนสอนเล่น |
| `js/store.js` | การต่อฐานข้อมูล Firebase |
| `js/firebase-config.js` | **ไฟล์เดียวที่คุณต้องแก้** ใส่ค่าจาก Firebase |
| `firestore.rules` | กฎความปลอดภัยของฐานข้อมูล ไว้คัดลอกไปวางใน Firebase |

ถ้ายังไม่ได้ใส่ค่าใน `firebase-config.js` เกมจะเปิดใน "โหมดในเครื่อง" เล่นได้บนเครื่องเดียว ห้องหายเมื่อรีเฟรช บทเรียนสอนเล่นใช้ได้ตามปกติ

---

## ขั้นที่ 1 · สมัครบัญชี

1. บัญชี Google (ใช้ของที่มีอยู่ได้) สำหรับ Firebase
2. บัญชี GitHub ที่ https://github.com/signup ชื่อผู้ใช้จะกลายเป็นชื่อเว็บ เช่น ใช้ชื่อ `mil-games` เว็บจะเป็น `mil-games.github.io`

## ขั้นที่ 2 · ตั้งค่า Firebase

1. เข้า https://console.firebase.google.com → **Create a project** → ตั้งชื่อ เช่น `himmaphan` → ปิด Google Analytics ได้ (ไม่จำเป็น) → Create
2. **เปิดการระบุตัวแบบไม่ต้องล็อกอิน**: เมนูซ้าย **Build → Authentication** → **Get started** → แท็บ **Sign-in method** → เลือก **Anonymous** → เปิด **Enable** → Save
3. **สร้างฐานข้อมูล**: เมนูซ้าย **Build → Firestore Database** → **Create database** → เลือกภูมิภาคที่ใกล้ไทย เช่น `asia-southeast1` (สิงคโปร์) → เลือก **production mode** → Create
4. **ใส่กฎความปลอดภัย**: ในหน้า Firestore กดแท็บ **Rules** → ลบของเดิมทั้งหมด → เปิดไฟล์ `firestore.rules` คัดลอกทั้งไฟล์มาวาง → **Publish**
5. **เอาค่าตั้งค่าเว็บ**: กดรูปเฟือง ⚙ ข้าง Project Overview → **Project settings** → เลื่อนลงไปที่ **Your apps** → กดไอคอน `</>` (Web) → ตั้งชื่อแอป เช่น `himmaphan-web` → **ไม่ต้อง**ติ๊ก Firebase Hosting → Register app
6. หน้าจอจะแสดงโค้ดที่มี `const firebaseConfig = { apiKey: ..., ... }` คัดลอกค่าทั้ง 6 บรรทัด ไปแทนที่ค่า `"ใส่ของคุณ"` ในไฟล์ `js/firebase-config.js` แล้วบันทึก

> ค่า `apiKey` ของ Firebase บนเว็บเป็นค่าที่เปิดเผยได้ตามปกติ คนอื่นเห็นได้ไม่เป็นไร ความปลอดภัยของข้อมูลมาจากกฎในข้อ 4

## ขั้นที่ 3 · ขึ้นเว็บด้วย GitHub Pages

1. เข้า https://github.com/new → ช่อง Repository name ใส่ `himmaphan` → เลือก **Public** → **Create repository**
2. ในหน้าที่ขึ้นมา กดลิงก์ **uploading an existing file**
3. ลาก**ของทั้งหมดในโฟลเดอร์นี้** (index.html, โฟลเดอร์ css, โฟลเดอร์ js และไฟล์อื่นๆ) ไปวางในช่อง ต้องให้ `index.html` อยู่ชั้นนอกสุด ไม่ใช่อยู่ในโฟลเดอร์ย่อยอีกชั้น → กด **Commit changes**
4. ไปที่แท็บ **Settings** ของ repository → เมนูซ้าย **Pages** → ช่อง Source เลือก **Deploy from a branch** → Branch เลือก `main` และ `/ (root)` → **Save**
5. รอ 1–3 นาที รีเฟรชหน้า Pages จะขึ้นลิงก์เว็บ เช่น `https://mil-games.github.io/himmaphan/`

## ขั้นที่ 4 · อนุญาตให้เว็บใช้ Firebase

1. กลับไปที่ Firebase → **Build → Authentication** → แท็บ **Settings** → **Authorized domains** → **Add domain**
2. ใส่ `ชื่อผู้ใช้.github.io` (เช่น `mil-games.github.io` ไม่ต้องมี https และไม่ต้องมี /himmaphan) → Add

## ขั้นที่ 5 · ทดสอบ

1. เปิดลิงก์เว็บ ถ้าไม่มีกรอบ "โหมดในเครื่อง" ขึ้นที่หน้าแรก แปลว่าต่อฐานข้อมูลสำเร็จ
2. ใส่ชื่อ → เปิดห้อง → เลือกเทพ → กด **คัดลอกลิงก์** ส่งให้เพื่อนใน LINE
3. เพื่อนเปิดลิงก์ ใส่ชื่อ เลือกเทพ แล้วคุณกด **เริ่มเกม**

เพื่อนจะเข้าห้องได้สองวิธี คือกดลิงก์ หรือพิมพ์รหัสห้อง 6 ตัวที่หน้าแรก

## ขั้นที่ 6 · (แนะนำ) เปิดให้ผูกบัญชี Google

ปกติเว็บจำผู้เล่นไว้ในเบราว์เซอร์ เน็ตหลุดแล้วกลับมาก็เล่นต่อได้ แต่ถ้าเปลี่ยนเครื่อง จะกลายเป็นคนใหม่ ปุ่ม "ผูกกับ Google" ที่หน้าแรกช่วยเรื่องนี้ ต้องเปิดใน Firebase ก่อน

1. Firebase → **Security → Authentication** → แท็บ **Sign-in method** → **Add new provider** → **Google**
2. กด **Enable** → ช่อง Support email เลือกอีเมลของคุณ → **Save**

ผู้เล่นที่ผูกแล้ว ไปเปิดเว็บในเครื่องใหม่ กด "ใช้ Google ที่ผูกไว้" จะกลับมาเป็นคนเดิม ห้องเดิมอยู่ครบ

ถ้าเพื่อนไม่ได้ผูก Google แล้วเปลี่ยนเครื่อง: ให้เขาเปิดลิงก์ห้อง จะเห็น "รหัสเครื่องนี้" ให้ส่งรหัสมา แล้วคนที่ยังอยู่ในห้องกด "เพื่อนเปลี่ยนเครื่อง? ย้ายที่นั่งให้" วางรหัส

## เมื่ออยากแก้เกม

- แก้กติกา ตัวเลข การ์ด หรือเทพ: แก้ใน `js/rules.js`
- แก้หน้าจอหรือบทเรียน: แก้ใน `js/app.js`
- อัปโหลดไฟล์ที่แก้แล้วทับของเดิมใน GitHub (Add file → Upload files) รอ 1–2 นาทีเว็บจะอัปเดตเอง
- ห้องที่กำลังเล่นค้างอยู่ตอนเปลี่ยนกติกาใหญ่ๆ อาจทำงานแปลก แนะนำให้เปิดห้องใหม่

## เรื่องค่าใช้จ่าย

ทั้ง GitHub Pages และ Firebase ไม่เสียเงิน ถ้าใช้ไม่เกินโควตาฟรี โควตาฟรีของ Firestore ([ดูหน้าทางการ](https://firebase.google.com/docs/firestore/quotas)) คือ อ่านข้อมูล 50,000 ครั้งต่อวัน เขียน 20,000 ครั้งต่อวัน และเก็บข้อมูลได้ 1 GiB

ในเกมนี้ การเดินหนึ่งครั้ง = เขียน 1 ครั้ง + อ่านตามจำนวนคนที่เปิดห้องอยู่ เกมหนึ่งเกมใช้ราวไม่กี่ร้อยครั้ง จึงเล่นได้หลายสิบถึงหลายร้อยเกมต่อวันโดยไม่เสียเงิน (ตัวเลขนี้เป็นการประมาณ ไม่ได้วัดจริง) ถ้าเกินโควตา Firebase จะหยุดรับข้อมูลจนถึงวันถัดไป และจะไม่เก็บเงินถ้าคุณไม่ได้ผูกบัตร

## ข้อจำกัดของเวอร์ชันนี้

- การ์ดรบของฝ่ายบุกเก็บไว้ในฐานข้อมูลก่อนฝ่ายรับเลือก หน้าจอไม่แสดง แต่คนที่เปิดดูข้อมูลดิบเป็นอาจเห็นได้ เหมาะกับเล่นกับเพื่อนที่ไว้ใจกัน
- กฎความปลอดภัยกันคนนอกห้องไม่ให้แก้ห้อง แต่ไม่ได้ตรวจว่าแต่ละการเดินถูกกติกาหรือไม่ (ตรวจอยู่ในหน้าเว็บ) ถ้าวันหนึ่งเปิดให้คนแปลกหน้าเล่นจำนวนมาก ควรย้ายการตรวจกติกาไปไว้ฝั่งเซิร์ฟเวอร์
- การ์ด "ญาณหยั่งรู้" ยังไม่เปิดใช้
- ผู้เล่นถูกจำด้วยเบราว์เซอร์ ถ้าเปลี่ยนเครื่อง ล้างข้อมูลเบราว์เซอร์ หรือเปิดโหมดไม่ระบุตัวตน จะกลายเป็นผู้เล่นใหม่ แก้ได้ด้วยการผูก Google หรือย้ายที่นั่ง (ขั้นที่ 6)
